EL KHOT | الخط — نسخة محسّنة قابلة للتثبيت (PWA)

التعديلات:
- تصحيح اسم العلامة إلى EL KHOT | الخط.
- تحسين التوافق مع شاشات الجوال والأجهزة اللوحية وسطح المكتب.
- إضافة تجربة تثبيت التطبيق لأجهزة Android والمتصفحات الداعمة.
- إرشادات تثبيت iPhone/iPad عبر Safari وميزة Add to Home Screen.
- بعد التثبيت تظهر دعوة مشاركة رسالة لصديق مرة واحدة؛ المشاركة تفتح قائمة المشاركة أو واتساب، ويؤكد المستخدم الإرسال بنفسه.
- إضافة manifest وأيقونات تطبيق وService Worker لتخزين ملفات الموقع الأساسية للاستخدام عند ضعف/انقطاع الاتصال بعد أول زيارة.

مهم للنشر:
- ارفع كل الملفات والمجلدات كما هي إلى نفس استضافة الموقع، مع إبقاء المسارات في جذر الموقع.
- يجب أن يعمل الموقع عبر HTTPS (الرابط الحالي على Vercel مناسب).
- تثبيت iOS يتم يدويًا من Safari: مشاركة > إضافة إلى الشاشة الرئيسية. لا يستطيع الموقع إظهار نافذة تثبيت أصلية على iOS مثل Android.
- مشاركة الرسالة لا ترسلها سرًا أو تلقائيًا؛ يختار المستخدم المستلم ويضغط إرسال في تطبيق المشاركة.
- اختبر السلة وواتساب ورقم التواصل وبيانات المنيو على الموقع المنشور قبل اعتماد النسخة النهائية.
